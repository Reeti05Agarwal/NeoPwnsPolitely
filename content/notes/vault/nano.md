## Summary of Key Commands

- **Save File**: `Ctrl + O`
- **Exit Nano**: `Ctrl + X`
- **Confirm Save**: `Enter` after `Ctrl + O`
- **Save Changes on Exit**: `Y` when prompted
- **Search**: Use `Ctrl + W` to search for text within the file.
- **Cut and Paste**: Use `Ctrl + K` to cut a line and `Ctrl + U` to paste it.
- **Help**: Press `Ctrl + G` to access the help menu for more commands and options.

## Using Nano Editor to Save and Exit Files

Nano is a popular text editor in Linux, known for its simplicity and ease of use. Here's how you can save and exit files in Nano:

## Saving a File in Nano

To save a file in Nano, follow these steps:

1. **Edit the File**: Make your changes or additions to the file as needed.
2. **Save the File**:
    - **Keyboard Shortcut**: Press `Ctrl + O` (denoted as `^O` in Nano).
    - **Prompt to Confirm File Name**: Nano will prompt you to confirm the file name. The default name displayed will be the current file's name.
    - **Press Enter**: If the displayed name is correct, simply press `Enter` to save the file. If you want to save it under a different name, type the new name and then press `Enter`.

## Exiting Nano

To exit Nano, follow these steps:

1. **Exit Command**:
    - **Keyboard Shortcut**: Press `Ctrl + X` (denoted as `^X` in Nano).
2. **Unsaved Changes**:
    - If there are any unsaved changes, Nano will prompt you to save the changes. Press `Y` to save, `N` to discard changes, or `Ctrl + C` to cancel the exit and return to the editor.

Nano is a straightforward editor, making it an excellent choice for beginners and quick text edits. Remember these key shortcuts to efficiently save and exit files while using Nano.

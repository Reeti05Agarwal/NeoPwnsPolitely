## **CIS Controls (Center for Internet Security)**

### Overview:

The **CIS Controls** are a prioritized set of cybersecurity best practices developed by the Center for Internet Security (CIS). These controls help organizations defend against known cyber threats effectively.

### Key Features:

1. **20 CIS Controls (Version 8):**
    
    - Grouped into three implementation groups (IGs) based on organizational maturity:
        - **IG1:** Basic cyber hygiene (small organizations with limited resources).
        - **IG2:** More advanced practices for medium-sized organizations.
        - **IG3:** Comprehensive measures for large enterprises.
2. **Categories:**
    
    - Inventory and Control of Assets.
    - Secure Configuration of Software and Hardware.
    - Continuous Vulnerability Management.
    - Access Control and Monitoring.
3. **Focus:** Practical, actionable steps to protect systems and data.
    

### Application:

- Widely used in government, education, healthcare, and private sectors.

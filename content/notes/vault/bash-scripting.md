## Create Script
```shell
nano script.sh
```
## Add Shebang
```shell
#!/bin/bash
```
## Make script executable
```shell
chmod +x script.sh
```
## Run the script
```bash
./script.sh
```

## `echo` Print 
```shell
echo "File Operations Script"
```

## `read` Input
```shell
read -p "Enter the File name: " file
# -p : print
```

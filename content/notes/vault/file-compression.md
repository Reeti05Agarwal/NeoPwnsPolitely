## `tar`

Create a tar archive
```jsx
tar -cvf archive.tar files
```

Extract files from a tar archive:
```jsx
tar -xvf archive.tar
```



## `gzip`

Compress a file with gzip:
```jsx
gzip filename
```

Decompress a gzip-compressed file:
```jsx
gunzip filename.gz
```

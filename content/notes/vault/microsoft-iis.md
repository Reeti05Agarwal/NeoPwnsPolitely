- IIS : Internet Information Services
- Extensible web server software developed by Microsoft for use with windows NT family
- Use to host websites/web apps and provides administrators with a GUI for managing websites
- Host both statis and dynamic websites developed in ASP.NET and PHP
- Ports: 80 / 443
- Supported executable files:
	- .asp
	- .aspx
	- .config
	- .php
